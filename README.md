## Hi, I’m Peter

**Data and AI engineer.** I work across the full data path, from the app event on a phone to the dashboard or LLM feature that depends on it. I make sure the data underneath is right.
 
Most of my work sits where data engineering, AI and mobile meet. I design event schemas that won't need a rewrite in six months, build the pipelines and monitoring behind them, and ship LLM features I can measure.
 
## What I work on
 
- **LLM applications:** RAG and agentic workflows, built to be reliable and testable
- **Data pipelines:** BigQuery and dbt, with event schemas built to last
- **Observability:** OTel, Grafana and SLOs for telemetry and IoT pipelines
- **Edge and on-device ML:** from notebook to production, offline and fast
- **Mobile analytics:** React Native instrumentation feeding the warehouse
